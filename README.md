
# 📊 Sales Data Analysis Using Microsoft Excel

## 📌 Project Overview

This project focuses on analyzing sales data using Microsoft Excel to identify business trends, evaluate sales performance, and generate meaningful insights.

## 🎯 Project Objectives

- Analyze total sales and revenue.
- Identify top-performing products.
- Compare sales performance across regions.
- Evaluate monthly sales trends.
- Support data-driven business decisions.

## 🛠️ Tools & Technologies

- Microsoft Excel
- Pivot Tables
- Excel Formulas
- Data Visualization
- Interactive Dashboards

## 📁 Project Structure

- `Dataset/` – Raw sales data.
- `Analysis/` – Data analysis and calculations.
- `Dashboard/` – Sales dashboard.
- `README.md` – Project documentation.

## 📈 Key Performance Indicators (KPIs)

- Total Revenue
- Total Orders
- Average Order Value
- Top-Selling Product
- Regional Sales Performance

## 🔍 Analysis Process

1. Data Collection
2. Data Cleaning
3. Exploratory Data Analysis
4. Pivot Table Analysis
5. Dashboard Development
6. Business Insights
